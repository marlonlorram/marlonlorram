## About

I work on two fronts: game security and backend engineering.

On the security side, I study how games and their protection systems work internally:
analyzing native binaries, documenting undocumented behavior, and building tooling for
instrumentation and reverse engineering.

On the backend side, I build APIs and services with Go, Java/Kotlin and NestJS,
and mobile clients with Flutter. Knowing what runs underneath the application layer
shapes how I design what runs on top of it.
